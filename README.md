# pytorch-shield
**Architecting Assured Autonomy in PyTorch**

This project implements a **Differentiable Safety Layer** (Lagrangian penalty) to enforce safety constraints directly within the neural network's loss function, aligned with **UL 4600** standards.

## Objective
To prove that autonomous agents can be trained for maximum performance without ever violating safety-critical boundaries.
